# AluraBooks 📚

Projeto desenvolvido durante os estudos de HTML e CSS, inspirado na plataforma AluraBooks. O site apresenta um catálogo de livros com layout moderno e responsivo, utilizando técnicas de Flexbox, CSS, organização de componentes e adaptação para diferentes tamanhos de tela.

### 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* Swiper.js
* Google Fonts

### 📱 Funcionalidades

* Catálogo de livros
* Carrossel de recomendações
* Menu responsivo
* Layout adaptável para celular, tablet e desktop
* Seção "Minha Estante"
* Interface inspirada em plataformas de leitura

Este projeto foi desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web front-end e design responsivo.
